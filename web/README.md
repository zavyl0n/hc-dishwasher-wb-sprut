# Веб-страница посудомойки

Отдельная страница для телефона и компьютера: `http://<адрес Wiren Board>/dishwasher/`.
Показывает то же устройство, что и правило `dishwasher.js`, и управляет им через MQTT контроллера.
Sprut.hub для неё не нужен, облако и интернет — тоже: шрифт, значки и код лежат на контроллере.

```
Браузер ⇄ nginx на WB (/mqtt) ⇄ mosquitto ⇄ правило dishwasher.js ⇄ hcpy ⇄ посудомойка
```

Что на странице:

- **Мойка** — состояние и сколько осталось, этапы, выбор программы и опций, запуск сразу,
  через N часов или «посуда нужна к ЧЧ:ММ», отмена с подтверждением, питание.
- **Состояние** — соль, ополаскиватель, фильтр, уход за машиной, дверь, прогнозы расхода,
  последняя мойка, Wi-Fi, прошивка, журнал событий с момента открытия страницы.
- **Настройки** — настройки самой машины из правила (жёсткость воды, ополаскиватель, громкость…).

Страница ничего не решает сама: она нажимает те же контролы, что веб-интерфейс WB и Sprut.hub.
Все проверки (дверь, удалённый старт, возврат переключателя через 15 с) остаются в правиле.
Набор программ, опций и настроек берётся из правила, поэтому страница подходит и к правилу,
собранному генератором под другую модель.

## Установка

Нужны Wiren Board со штатным веб-интерфейсом и установленное правило `dishwasher.js`.
На контроллере, из папки набора:

```bash
bash web/install_web.sh
```

Скрипт копирует `web/app` в `/var/www/static/dishwasher`, кладёт настройку nginx в
`/etc/nginx/includes/default.wb.d/dishwasher.conf`, проверяет её (`nginx -t`) и перечитывает nginx.
Если nginx настройку не принял, прежнее состояние возвращается. Удаление: `bash web/install_web.sh --remove`.

Обновление — тот же запуск из новой версии набора; `config.js` остаётся прежним.
После перепрошивки контроллера (не обновления пакетов) запустите скрипт ещё раз.

На телефоне страницу удобно добавить на домашний экран («Поделиться» → «На экран Домой» или меню браузера).

## Настройки страницы

`/var/www/static/dishwasher/config.js`:

| Поле | Значение |
|---|---|
| `device` | id устройства WB, по умолчанию `dishwasher` (как `CFG.id` в правиле) |
| `mqtt` | адрес MQTT по WebSocket; пусто — `ws://<адрес страницы>/mqtt`, штатный прокси WB |
| `demo` | `true` — страница работает без контроллера, с имитацией машины |

Те же настройки на один раз задаются в адресе: `?demo=1`, `?mqtt=ws://192.168.1.10:18883`, `?device=…`.

## Доступ

- Страница открыта всем, кто видит веб-интерфейс контроллера, — как и его собственные панели.
- Если в веб-интерфейсе WB заведены пользователи, `/mqtt` пускает только вошедших: сначала войдите
  в интерфейс WB в том же браузере. Подходит любая роль — всем им разрешена запись в `/devices/#`.
- Снаружи домашней сети страница не видна, пока вы сами не откроете к контроллеру доступ.

## Если не работает

| Что видно | Что проверить |
|---|---|
| «Нет связи с контроллером» | вы в домашней сети? вошли в веб-интерфейс WB, если там есть пользователи? `systemctl status nginx mosquitto` |
| «Устройство не найдено» | правило загружено: `journalctl -u wb-rules -n 30 --no-pager`; `device` в `config.js` совпадает с `CFG.id` |
| «Машина не на связи» | hcpy и Wi-Fi машины — раздел «Диагностика» в основном README |
| После обновления старый вид | обновите страницу; настройка nginx из набора запрещает браузеру хранить старые файлы |

## Разработка

Без сборки и зависимостей: `web/app` — готовые статические файлы (ES-модули).

```bash
cd web/app && python3 -m http.server 8080      # http://127.0.0.1:8080/?demo=1
```

- `js/mqtt.js` — клиент MQTT 3.1.1 поверх WebSocket (QoS 0), сам переподключается.
- `js/store.js` — значения и описания контролов устройства; запись с ожиданием подтверждения.
- `js/model.js` — из значений контролов собирает то, что показывает экран (без DOM).
- `js/ui.js` — экран. `js/sim.js` — имитация правила и машины для демо-режима и тестов.
- `tools/fake-wb.mjs` — та же имитация, но через настоящий брокер: страница работает с ней
  как с контроллером (нужен mosquitto со слушателем WebSocket, пример настройки — в начале файла).

Тесты — `npm test` в корне набора (`tests/web_*.test.js`). `web_sim.test.js` сверяет контролы
имитации с настоящим правилом: изменили контролы в `rule/dishwasher.js` — поправьте `js/sim.js`.

Шрифт [Onest](https://github.com/simpals/onest) (SIL OFL 1.1) и значки [Lucide](https://lucide.dev) (ISC)
лежат в `app/fonts` и `app/js/icons.js` вместе с текстами лицензий.
